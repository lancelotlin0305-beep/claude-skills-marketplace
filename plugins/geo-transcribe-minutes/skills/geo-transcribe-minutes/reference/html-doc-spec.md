# HTML/SVG 文件產出規範

最終交付的「會議記錄」或「技術傳承文件」是**單檔自足 HTML**:所有 CSS/SVG 內嵌、零外部資源(不引 CDN、不引網路字型、不引外部圖片),點開即看、可直接列印(A4)或寄出。以 `templates/meeting.html` / `templates/handover.html` 為骨架填內容,不要從零手刻。

## 視覺語言

兩份模板風格不同,**照各自模板走,不要混用**:

- **meeting.html(編輯級文件風)**:CSS 變數雙主題(淺/深色自動切換,`prefers-color-scheme`
  +`data-theme` 覆寫都支援)、mono 小標、決議藍塊 `.dec`/未拍板紅塊 `.nodec`、
  卡關列紅底 `.blk`+`.tag`、風險/未解/延後 `.card` 網格。顏色一律用 CSS 變數,
  不要寫死色碼(SVG 文字用 `style="fill:var(--ink)"` 讓深色模式跟著變)。
- **handover.html(淺色卡片風,與 geo 系列一致)**:淺灰底 `#f4f6fa`、白卡、
  區塊左緣 4px 專色帶(藍 `#2563eb`、綠 `#059669`、橘 `#d97706`、紫 `#7c3aed`、
  紅 `#dc2626`、青 `#0891b2`),同概念跨區同色。
- **中文字型堆疊**:`"Noto Sans TC","Microsoft JhengHei","PingFang TC",sans-serif`。
- **列印**:`@media print` 已在模板內——卡片避免跨頁截斷、深色背景轉淺、`<details>` 展開。

## SVG 圖表(內嵌,手寫可控的簡單圖)

本 skill 的 SVG 限定**簡單、資料驅動、座標可心算**的圖;複雜架構圖不要在這裡手刻,改呼叫 `geo-infographic-style`(資訊圖表)或 `geo-bpmn-flow-builder`(流程圖)產 SVG 後,把其 `<svg>` 內容嵌入本文件對應區塊。

可手刻的三種:

1. **議程/章節時間軸**(兩種模式皆用):橫向長條,總長=音檔時長,依議題/章節切段上色,段上標題+起訖時間。`viewBox="0 0 1000 90"`,x 座標=秒數/總秒數*1000。段數 >8 時改直式清單,不硬塞。
2. **發言佔比條**(會議模式,有 speaker 資料才畫):單條堆疊橫條,每人一色+百分比標籤。
3. **步驟流程帶**(技術傳承模式):步驟 ≤6 時畫「圓角矩形+箭頭」橫向流程;>6 步改直式編號清單。

SVG 規則:`<svg>` 一律帶 `viewBox` 並以 CSS `width:100%; height:auto` 縮放;文字最小 14px(以 viewBox 1000 寬為基準);顏色沿用上方色盤;不可與文字內容重複資訊以外的裝飾動畫。

## 兩種文件的區塊結構

### 會議記錄(meeting.html)——內容一律取自 minutes.json

1. 頁首:會議名稱、日期/時間/地點/主持、與會者 chips(請假者刪除線+「請假」)
2. 結論摘要(tldr,3–7 條含時間戳)
3. 議程時間軸 SVG(agenda_items 的 ts 多為 null 時整節刪)
4. 決議摘要表(D01…,拍板內容/拍板者/出處時間戳;無決議整節刪)
5. 行動項表(A01…,卡關列紅底置頂,owner null→待指派、due null→due_raw 淡色)
6. 議題討論(每議題:摘要→方案 opts→決議 .dec 或未拍板 .nodec)
7. 風險/未解問題/延後事項卡片網格(空陣列整節刪)
8. 附錄:順稿版逐字稿(`<details>` 預設收合,分段含時間戳與發言者)
9. 頁尾:免責聲明(欄位僅取自來源、未推測補齊)+來源/引擎/日期/版號+待確認清單

**空值鐵則**:null 顯示「—」或整塊省略;空陣列的 section 連標題一起拿掉,不留空殼。

### 技術傳承文件(handover.html)

1. 頁首:主題、講者、日期/時長
2. 摘要卡(藍):這份文件能學到什麼(3–5 條)
3. 章節時間軸 SVG
4. 架構與脈絡(紫):文字說明+嵌入外部 skill 產的架構/流程 SVG(若有)
5. 操作步驟(青):步驟流程帶 SVG+逐步說明,指令用 `<code>` 區塊
6. 眉角與陷阱(橘):一坑一卡,含時間戳——版面上最醒目的區塊
7. Q&A(綠):`<details>` 問答對
8. 相關資源表
9. 附錄逐字稿+頁尾(同會議記錄)

## 命名與交付

輸出資料夾與檔名以 **SKILL.md「產出」表為唯一權威**,此處不重複。
迭代進版:使用者修改後要求更新時,比對差異、文件頁尾版號 `vN` 遞增並列變更摘要。
