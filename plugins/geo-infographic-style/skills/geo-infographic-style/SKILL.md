# 資訊圖表繪製(統一風格)

以固定視覺語言把任何結構化資料繪成簡報可讀的資訊圖表。三原則:**一個群組一張卡、一個專色**(顏色即身分);**文字區淺色、素材可搶眼**(承載文字的表面用白底/淺漸層,素材與插圖可深色飽和發光以抓眼球——§2 表面分類);**文字載資訊、插圖做質感**(文案逐字忠於原始資料,插圖拿掉後資訊仍完整)。

## 工作流程(6 步)

1. **確認豐富度等級**:使用者已指定則採用;未指定**先詢問**——1 線框/2 立體/3 素材場景,附情境建議:草稿 1、簡報內容頁 2、封面/重點頁 3(規格 §13)。
2. **選版型**:先問「這份資料的**主要溝通意圖**是什麼」,依下方「意圖 → 結構」框架定主版型,次要關係用疊加語彙表達。
3. **先文後框**:讀規格 §6,逐卡斷行(全形 19–21 字/行、填滿行寬),量最寬行推卡寬卡高;依用途定畫布(§10:自適應 1600–1720 / 16:9 1920×1080 / A4 1240×1754),超載一律拆圖不縮字。
4. **取素材**(選第 3 級或要求擬真素材才做,拆卡後每卡素材需求已明確):依 `references/asset-generation.md`——先選路徑,再問素材來源→是否 AI 產圖→**本機能否外呼**(不能則走「Prompt 交接」由使用者代產貼回)→產圖→**一律去背成透明 PNG**(`chroma_key.js` 自動偵測底色,與底色無關)→留存素材+prompt→驗收。
5. **繪 SVG → 轉檔**:單一檔案;**版型有對應生成器時優先改其資料重用**;defs 用 `node scripts/inject_defs.js 圖.svg` 自動注入;第 3 級素材以 `<image>` 嵌入(自帶光影不疊 SVG 投影)。完成跑 `node scripts/render.js 圖.svg` 出 2 倍解析度 PNG。
6. **自檢 → 交付**:逐項核對下方檢核清單,不過就修正重轉;單獨繪圖交付 PNG+SVG,在簡報/proposal 流程中將 PNG 嵌入該頁、SVG 一併附上。

繪製前必讀 `references/style-spec.md`(色彩、立體、元件、連接、插圖、字級、數據語彙、KPI 列、版型細則、頁面模式、易讀原則、裝飾層的**唯一出處**);第 3 級另讀 `references/asset-generation.md`。

## 版型:意圖 → 結構(先問意圖,再選版型)

先判斷資料的**主要溝通意圖**,再對應結構。混合結構取**最主要**一種為骨幹,次要關係用疊加語彙(如箭頭標流向、KPI 疊加)表達;實在對不上就**拆成多張單一訊息圖**(§11),不硬塞或自創版式。

| 溝通意圖 | 主版型 | 佈局要點 |
|---|---|---|
| **比較差異** | 比較 / Venn | 等寬卡並排逐列對齊;或 2–3 圓相交表達重疊(§9) |
| **呈現時序/演變** | 流程 / 時間軸 | 有分支→流程(上升軸/山形/箭頭鏈);純時序無分支→時間軸 zig-zag(§9) |
| **呈現流程/步驟** | 流程 / 循環 | 有序階段走流程軸;首尾相接走循環弧線箭頭順時針 |
| **呈現結構/層級** | 階層 / 中心輻射 / 環形放射 | 金字塔或樹狀;一核多群→中心輻射;一主多面→環形放射 |
| **呈現分類/並列** | 分組並列 | 全寬橫帶堆疊或卡片網格,不畫連接線 |
| **呈現佔比/數據** | 數據 | 人形比例圖/百分比橫條/單位方塊/圓餅甜甜圈(§7) |
| **呈現空間/地理** | 地理標註 | 地圖輪廓 + 編號圓徽/比例符號 + 引線說明卡(§9) |
| **呈現關係/網絡** | 中心輻射 / 標註 | 核心 + 群組虛線相連;或中央情境 + 編號引線說明 |

**閱讀骨架**:整張圖依「引子→核心→結論」安排,重要元素順 F/Z 視線動線放(§11.5–11.6)。數據語彙(§7)與 KPI 大數字列(§8)可與**任何版型**疊加。各版型細則見 §9。

每卡項目 2–5 條,超過就拆卡;敘述型內容保持段落,不硬轉清單。

**參考生成器(有對應時優先改其資料重用,不從零手繪)**:角色/中心輻射 → `scripts/gen_role.js`;流程/roadmap → `gen_blueprint.js`(平行卡)、`gen_blueprint2.js`(階梯成長);其餘手繪。素材:單物件去背 → `gen_assets.js`;整組呼應文字的場景 → `gen_scene.js`。

## 交付前檢核(規則細節見 style-spec 對應節次,此處只列驗收點)

**硬性紅線(任一不過 = 重做,每張必掃):**
- [ ] **內容忠實**:文案逐字一致、無遺漏、無擅自增寫;雙語成對;重繪已逐項回對原圖標籤與連接關係(起訖、方向)(§內容忠實)
- [ ] **卡寬/留白**:卡寬貼合內容、governing 卡右內距 16–40px、無固定寬大留白;填充率 ≥ 55%(§3.1)
- [ ] **間距達標**:子元件距卡框 ≥ 12px、並排膠囊 ≥ 20px、標題距子元件 ≥ 14px、流程節點 ≥ 40px(§3.1、§4)
- [ ] **淺色(文字區)**:承載文字的表面無深色大面積底、皆漸層;**素材/重點卡的深色屬允許**(§2 表面分類),但重點卡文字須白字且對比 ≥ 4.5:1
- [ ] **字級 ≥ 下限**:內文 ≥ 16px、全圖最小 14.5px(§6)
- [ ] **零重疊**:箭頭/連線與卡片零重疊、迴圈線走空檔、標籤不壓卡(§4)

**品質項(依本張用到的版型/元素抽測,沒用到的略過):**
- [ ] 同層級同版式、等寬等距;群組差異只用顏色不用結構(§一致性)
- [ ] 立體四件套完整:主卡雙層陰影+厚度邊、深色列三段漸層、子卡/列/徽章各級投影;插圖光源一致左上(§2、§5)
- [ ] **帶素材的卡用圖文並置**:主圖區 35% + 右清單 65%、左右鏡像;素材未塞右上角造成清單列半空(§14、§3.1)
- [ ] **中心輻射版型**:中央帶由連線/KPI/核心卡佔用非僅裝飾;核心卡維持淺色;場景素材落地共用地平線(§14、§12)
- [ ] **三級同構**:1–3 級版面骨架一致,只主圖區與裝飾/場景豐富度遞增(§13)
- [ ] 預留 = 虛線+時鐘+灰字、底部有圖例(§3)
- [ ] 數據/易讀:輪色正確、數值直標帶單位、關鍵數字放大、未達成=中性灰;單圖單訊息、三段敘事、F/Z 動線(§7、§11)
- [ ] 頁面模式正確(自適應/16:9/A4);內容超載已拆圖非縮字(§10)
- [ ] 豐富度=使用者確認等級;第 3 級素材取自素材庫或經同意的 AI 產圖(含 Prompt 交接),**整張圖未交生成模型重繪、承載資訊文字由 SVG 負責**(§13、§5)
- [ ] 走 AI 產圖/交接時:已依序詢問來源→是否產圖→能否外呼→(供應商/交接);素材與 prompt 已留存(prompts.json);**金鑰未寫入任何 skill 檔或圖檔**(asset-generation.md)

## 迭代

使用者的修改回饋若可通用化(新排版規則、色彩偏好、新版型),應建議寫回本 skill 的規格檔並重新打包,讓下次產圖直接受益。
