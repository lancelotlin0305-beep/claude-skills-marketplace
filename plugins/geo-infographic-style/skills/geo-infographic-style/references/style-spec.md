# 風格規格(唯一出處)

## 1. 色彩

群組依序取色:**藍 → 綠 → 橘 → 紫 → 紅 → 青綠 → 藍灰 → 棕金**。每色四層次(新增色相時依同明度邏輯推導):

| 色相 | 主色(邊框/勾選) | 深色(標題/膠囊) | 淺底 | 淡邊 |
|---|---|---|---|---|
| 藍 | `#2F54D1` | `#2444B8` | `#F5F8FF` | `#DDE5F7` |
| 綠 | `#1F9254` | `#177A44` | `#F3FBF6` | `#D8EEDF` |
| 橘 | `#E8850C` | `#C86F04` | `#FFF8EF` | `#F6E3C6` |
| 紫 | `#6D3FC0` | `#5B2FAE` | `#F8F5FF` | `#E6DCF7` |
| 紅 | `#C62839` | `#B01F30` | `#FFF5F6` | `#F3D5D9` |
| 青綠 | `#2E9E5B` | `#1E7A46` | `#FBFDFC` | `#DFEAE3` |
| 藍灰 | `#5A6E8C` | `#47597A` | `#F6F8FB` | `#DDE3EC` |
| 棕金 | `#B08A2E` | `#8F6E1F` | `#FBF8F0` | `#EDE3CB` |

固定色:標題深藍 `#122B6E`、強調藍 `#3E7BFA`、內文 `#2A3555`、說明灰 `#66708C`、英文副行灰 `#8A93A8`、預留灰字 `#9AA3B2`、預留圖示/虛線 `#A7B0BF`、數據中性灰 `#D9DDE3`。背景純白(海報式/場景式圖表可依 §12 改極淺漸層)。

語意慣例(有對應概念時優先):藍=一般使用者/第一階段、綠=專業/數據、橘=公眾/中期、紫=進階/願景、紅=管理/高權限/核心、青綠=基座/支撐/外部資源、藍灰=中性/技術模組、棕金=成果/價值層。「規劃中/預留」語意一律由灰色時鐘系統表達(§3),不佔用彩色。

## 2. 漸層與立體感(任何色塊不得單色平塗)

- 大面積底(群組帶/核心卡):專色淺漸層,頂 97–99% 明度 → 底 92–94% 明度(例:藍 `#F8FBFF → #E3ECFB`;八色完整代碼以 assets/defs.svg 為唯一出處)。
- 小面積深色(子卡標題列/膠囊):**三段漸層**「頂部受光 → 中間本色 → 底部收暗」(例:藍 `#628CF2 → #3A5CD4 → #1E379E`;各色與灰階版見 defs),並套標題列陰影 `hdr`。
- 白色膠囊:白 → 專色極淺(例:紫 `#FFFFFF → #F1EAFD`)+ 輕投影 `row`。
- 徽章:球面 radialGradient(亮心左上 cx=0.35、cy=0.3)+ 投影 `obj`。

**立體層次(強制,四件套)**:
1. **雙層陰影**:主卡用 `shadow` = 遠景大柔影(dy=9、blur=12、14%)+ 近景實影(dy=2、blur=3、10%)。
2. **厚度邊**:每張主卡底部墊一層同形狀、下移 6px 的專色薄片(opacity 0.16),模擬卡片側面厚度。
3. **三段漸層**:深色列與膠囊一律採用(見上)。
4. **元件投影**:子卡 `card2`(dy=4、blur=5、13%)、項目列/技術膠囊 `row`(dy=2、blur=2、10%)、徽章與插圖 `obj`(dy=4、blur=4、28%)。

生動化僅限漸層與陰影,不加紋理、光斑、動態。全部濾鏡與漸層代碼見 assets/defs.svg。

## 3. 元件

- **群組帶/卡**:圓角 18、2px 主色邊框、淺漸層底、陰影 `shadow`。
- **標題列**:球面漸層徽章(左上白色高光橢圓,內置白色職能圖示或編號)+ 深色標題 800 + 灰色說明 15px,一律靠左。徽章半徑依元件層級:全寬層帶/大卡 24–28、堆疊層/側卡 20–22、KPI 組 18。
- **膠囊標籤**:深色漸層底、白字 700、全圓角,寬度貼合字數;放一項關鍵屬性(階段/入口/狀態),無則省略。
- **子卡**(帶內分欄):白底、淡邊框 1.5、圓角 12;頂部深色漸層標題列(白字 17/700、filter `hdr`)。
- **項目列**:白底、圓角 10、淡邊框、高 40、間距 10;左側 `chk`(主色、直徑 20)+ 文字 16/500。
- **預留/後續年度項目**:虛線框(dasharray 5 4)+ `clk` 灰時鐘 + 灰字,不打勾;整卡預留則外框改虛線(8 6)、膠囊改灰三段漸層 `gHdrGray`(不得單色平塗)。圖底附圖例:「實線=本案範圍」「虛線+時鐘=後續擴充」。
- **段落文字**(敘述型內容):16px/500、行距 26,左內距 24、右內距 14–18。
- **雙語排版**(原始資料為中英雙語時):中文為主行(標題 800 / 要點 15.5/500),英文為副行(11.5/400、灰 `#8A93A8`,置於中文正下方);標題、要點、連接線標籤一律成對呈現,不得只譯一半。
- **圖示補位原則**:卡片內容點少於 3 條時,以主題相關圖示或擬 3D 小插圖平衡版面密度(對話泡泡、文件、趨勢圖、成品示意等),**嚴禁為湊滿版面而自行增寫文字**;圖示只補氛圍、不載資訊。
- **連接徽章**:流程箭頭上有標籤時,以白底圓角小徽章(淡邊框 + `row` 投影)騎在箭頭/卡縫上呈現,內放「中文粗體 + 英文小字」,不用裸文字貼在縫隙。

## 4. 連接語彙

- **輻射連線**:點狀虛線 `#9AA7C8`、2px、dasharray「2 6」;群組端主色圓點(r=5.5–7)、核心端深色圓點;水平/垂直走線,落點在對方元素範圍內。
- **流程軸線**:粗點虛線 5px、dasharray「0.1 13」、圓頭 + 強調藍 `#3E7BFA` 實心箭頭(**箭頭色規**:主軸箭頭=強調藍;支線/帶內/接入箭頭=來源或目標層專色);線下襯楔形 `gWedge`(z 序:楔形→線→卡片);每卡底邊短虛線垂降至軸線上的主色圓點(r=7、白邊 2、距卡底約 30px);箭頭與任何卡片 ≥ 6px 淨空。

## 5. 插圖(擬 3D)

每卡一組「主物件+配件」,取材群組職能:申辦→螢幕/表單、數據→長條圖、審核→檢核板/放大鏡、通報→大聲公、管理→齒輪/人物、圖資→疊層、AI→晶片+星芒、基座→疊層方塊。插圖只做氛圍不載資訊;全圖複雜度一致、光源統一左上。

立體感四件套:① 漸層上色(平面 linear、球體 radial)② 白色高光(圓形疊橢圓 opacity 0.25–0.55、平面疊斜切多邊形 0.10–0.22)③ 物件投影(filter `obj`)④ 地面扁橢圓陰影(色系深色、opacity 0.12–0.14)。

**外部素材庫(使用者自管,skill 不內含素材檔)**:去背 PNG 素材(命名 `P編號_英文名.png`)存放於使用者指定的素材目錄——Claude Code 以路徑指定(建議 `./geo-assets/`),Claude.ai 於對話中上傳所需素材。繪製第 4/5 級(§13)時先向使用者確認素材來源;有素材以 `<image>` 嵌入 SVG、依卡片比例縮放,**素材已自帶柔和光影,嵌入時不再疊 SVG 物件投影與地面橢圓**;缺件時開出「元素需求單」(項目 + 對應 prompt,參照 `scripts/asset_prompts.json`),由使用者以 Gemini 生成 → 專業去背工具處理(remove.bg、PhotoRoom 等;程式門檻硬切品質不足,不採用)→ 回傳透明 PNG,驗收(邊緣無毛邊、無殘留背景)後嵌入。1–3 級或無素材時依上方四件套現繪。

真 3D 元素一律外部生成;**整張圖永不交由影像生成模型重繪**;文字永遠由 SVG 負責(生成圖中文字易錯,插圖與文字必須分工)。

## 6. 文字

字型:`Noto Sans TC, Noto Sans CJK TC, Microsoft JhengHei`(轉檔環境需 Noto CJK)。簡報模式字級(任何文字 ≥ 14px):

| 用途 | 字級/字重 |
|---|---|
| 全圖主標 | 40 / 900(下加細藍底線 2.5px + 兩端小圓點) |
| 卡片/層標題 | 22 / 800 |
| 子卡標題列 | 17 / 700 |
| 全圖副標 | 17 / 400 |
| 內文/項目 | 16 / 500(最小內文) |
| 說明文字 | 15 / 400 |
| 膠囊標籤 | 14.5 / 700(全圖最小字) |

A4 直式模式(寬 1240)主標可降為 34/900,其餘字級不變。斷行規則:全形 19–21 字/行、以填滿行寬為目標;不足時依序:重新斷行 → 降一級字級 → 精簡文案(需回報使用者)。全形標點與「・」「|」直接使用。

## 7. 數據圖表語彙(統計/佔比/問卷資料)

共通規則:**多類別數據依配色順序輪用不同專色**——同一題的不同選項、不同列的人形圖、不同橫條、圓餅各扇區,各取一色,不得整組單色到底;僅單一指標(一條 bar、一個佔比)才用單色。KPI 列各組亦輪色。「未達成/其餘」一律中性灰 `#D9DDE3`(描邊 `#C6CCD6`);數值直標於元素旁(主色、700–900 字重),類別標籤 15–16px 灰 `#66708C`;不另設圖例(狀態圖例除外);數字必帶單位;關鍵數字放大至 24–32/900。

- **人形比例圖(pictogram)**:每列 10 個 `man` 人形(高 32、間距 8);達成=主色、部分達成=主色 opacity 0.55、未達=中性灰;列右側配百分比圓徽(主色圓 r=26 + 白字 18/900)與說明文字。
- **百分比橫條**:灰底軌道(高 30、全圓角、`#D9DDE3`)+ 主色三段漸層填充;數值標於條尾(主色 18/900)或條內白字;標籤在條右側。
- **單位方塊圖**:`unit` 圓角方塊(20×20、間距 6)橫列,達成主色/未達灰;適合「N 分之 M」「每 10 人有 M 人」。
- **圓餅/甜甜圈**:扇區 ≤ 6 片;最大扇區用主色,其餘同色相由深至淺;標籤以 1.5px 引線拉出,數值 20/900 主色 + 名稱 14 灰;甜甜圈中心放圖示或關鍵數字(28/900);圓餅整體套 `obj` 投影。
- **卡片迷你趨勢**:卡內折線/長條,主色 2.5px、不畫格線,只標首尾值。

## 8. KPI 大數字統計列

- 位置:全圖標題之下、主內容之上;3–5 組橫排等距。
- 每組結構:小圖示(主色線條圖示或球面徽章 r=18)+ 大數字(36–44/900 主色)+ 單位(18/700 同色、緊接數字)+ 標籤(15/400 灰,置於數字上方)。
- 組間以留白或 1px 淺灰豎線 `#E3E6EF` 分隔;可整列放於白卡(圓角 16 + `row` 投影)上,不用深色底。

## 9. 版型擴充細則

- **環形放射**:核心圓置中(白底 + 主題名 24/900 深藍 + `shadow`),外環以 3–8 段弧/扇承載類別(各取專色漸層);類別說明卡沿圓周外側放射排列,以短引線或弧段對應;含統計時 KPI 列置頂。
- **循環**:4–6 個節點(球面徽章 r=28 + 白卡標籤)沿圓周等分,節點間以主色 3px 弧線 + 實心箭頭順時針串接;中心放主題名或核心圖示。
- **階層—金字塔**:3–5 層梯形由上而下堆疊,依配色順序取色(頂層深、往下漸淺或逐色),層間留 4px 白縫,每層文字白字置中(不足時標籤外拉引線);整體套 `shadow`。
- **階層—樹狀**:頂節點用深色漸層標題列,子節點白卡(`card2` 投影),連線用直角線 `#9AA7C8` 2px;同層節點等寬等距。
- **標註型**:中央放情境示意區(擬 3D 插圖或示意底圖),四周說明卡(標準卡版式);每卡配編號圓徽(主色實心圓 r=14 + 白數字 15/700),以 1.5px 主色引線連至示意區對應位置,引線端點加 4px 圓點;編號自左上起順時針。
- **流程子樣式**:直線上升軸(預設)、山形折線(峰/谷交替放卡,折線段依序取專色)、箭頭鏈(chevron 箭頭一節一色、三段漸層,節下對應說明卡);皆遵守 §4 箭頭淨空與落點規則。
- **橫帶內小流程**:基礎層/支撐層橫帶內若含加工步驟(如「文件 → 向量化 → 知識庫」),以「圖示組 → 主色箭頭(附標籤)→ 圖示組 + 說明」的帶內敘事呈現,取代同款膠囊排排站;橫帶對主流程的支援關係以虛線箭頭連至對應階段卡並附標籤。

## 10. 頁面模式

| 模式 | 畫布 | 使用時機 |
|---|---|---|
| 自適應(預設) | 寬 1600–1720、高依內容 | 未指明用途的單獨繪圖 |
| 16:9 簡報頁 | 1920×1080 固定 | 指明放入簡報/proposal 單頁,或由 pptx 流程呼叫 |
| A4 直式報告 | 1240×1754 固定 | 指明放入報告/文件(docx/pdf) |

- 固定模式下:標題區高 ≤ 120(16:9)/≤ 140(A4);內容區置中排版;四周留白 16:9 ≥ 50、A4 ≥ 60。
- **內容超載一律拆成多張圖,禁止縮小字級或壓縮行距**;拆圖時每張仍須是完整可獨立閱讀的單圖單訊息。
- 上游流程(pptx/docx skill)呼叫時,依目標文件自動套用對應模式。

## 11. 易讀三原則(貫穿所有版型)

1. **單圖單訊息**:一張圖只回答一個問題;資料含多個主題時拆成系列圖。
2. **直標於圖上**:數值、類別直接標在元素旁,不依賴另設圖例(既有/預留狀態圖例除外)。
3. **數字說人話**:必帶單位、關鍵數字放大加粗;比較性數據排序後再呈現(大→小或時序)。

## 12. 裝飾層(填補留白,選用)

版面出現大面積留白(側掛式版型的 L 型角落、環形版型的四隅等)時,依本節填補。**裝飾一律不載資訊、不與內容元素重疊**,內容忠實原則不受影響。

- **背景**:純白可改為極淺縱向漸層(白 → `#EAF1FA` 一帶),僅限海報式/場景式圖表;簡報內容頁仍以純白為預設。
- **基礎裝飾**:柔光圓(四色淺底、opacity 0.4–0.55、r 55–110)、點陣(5×3、r 2.4、`#9DB4DC`)、十字星與四角星芒,散布於留白角落。
- **主題圖示徽底**:柔光圓上疊一個與主題相關的線條圖示(文件、節點網、放大鏡、晶片、齒輪、對話泡泡⋯依題材選),描邊取圓底同色系加深一階、stroke 2.5–4、fill none、opacity 0.6–0.85;零星小留白配獨立小型線條圖示(代碼括號、星芒等)。
- **主題呼應元素**:依題材加入場景意象——底座平台(同心橢圓 + 地面放射線)、城市天際線剪影(含白色窗格)、KPI 擬 3D 小圖示(金幣疊、人群、新芽、地球)等;色彩一律取淺色系。
- 用量節制:裝飾總面積不搶過內容;所有裝飾置於內容圖層之下。

## 13. 豐富度等級(1–5 級)

產圖前必須確認等級:使用者已指定則採用;未指定時先詢問並附情境建議——草稿討論=1、簡報內容頁=2、海報/成果頁=3、重點展示頁=4、封面/主視覺=5。

- **第 1 級|極簡線框**:單色細線(`#A7B0BF`)、無填色;§2 立體與 §12 裝飾全部關閉。
- **第 2 級|立體標準(預設基準)**:立體四件套(§2)全套;無裝飾層。
- **第 3 級|立體+裝飾**:第 2 級 + §12 裝飾層(淺漸層底、柔光圓、點陣、線條圖示徽底、底座平台);裝飾為抽象向量、退居背景、不搶內容。
- **第 4 級|素材嵌入**:第 3 級 + 關鍵位置嵌入外部生成擬真元素(每卡至多 1 件主題素材 + 帶內/底部少量元素);素材成為版面要角但數量節制。
- **第 5 級|全場景組合**:第 4 級 + 全景場景元素(遠近天際線、帶內機房/場景剪影、飄浮件、資料流與光點),形成完整場景敘事。

通則:4/5 級元素一律取自外部素材庫(§5),整張圖由 SVG 組裝、文字與版面 100% 可控;**嚴禁將整張圖交由影像生成模型重繪**(必產生文字錯誤與重複標籤)。
