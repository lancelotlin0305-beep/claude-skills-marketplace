| 綠 | `#1F9254` | `#177A44` | `#F3FBF6` | `#D8EEDF` |

語意慣例(有對應概念時優先):藍=一般使用者/第一階段、綠=專業/數據、橘=公眾/中期、紫=進階/願景、紅=管理/高權限/核心、青綠=基座/支撐/外部資源、藍灰=中性/技術模組、棕金=成果/價值層。「規劃中/預留」語意一律由灰色時鐘系統表達(§3),不佔用彩色。

## 2. 漸層與立體感(任何色塊不得單色平塗)

**表面分類(淺色原則的適用範圍)**——「全圖淺色」只約束**承載文字的表面**,不綁死素材:

| 表面類型 | 色彩規則 |
|---|---|
| **承載文字的表面**(群組帶/一般卡底/清單列/段落底) | **一律淺色淺漸層**(可讀性優先),不得深色大面積平塗。 |
| **素材/插圖區**(嵌入的 3D 素材、主圖區、裝飾場景) | **不受淺色限制**——可深色、飽和、發光,以抓眼球為目標;只要不壓到相鄰文字可讀性。 |
| **重點卡/封面卡/banner**(少數) | **允許深色飽和底襯托素材**;但**該卡文字一律改白字(或高對比色)並實測對比 ≥ 4.5:1**,深色底仍須漸層(禁單色平塗)。重點卡屬「刻意破格」,一張圖至多 1–2 張,其餘卡維持淺色以免失衡。 |

- 大面積底(群組帶/核心卡):專色淺漸層,頂 97–99% 明度 → 底 92–94% 明度(例:藍 `#F8FBFF → #E3ECFB`;八色完整代碼以 assets/defs.svg 為唯一出處)。
- 小面積深色(子卡標題列/膠囊):**三段漸層**「頂部受光 → 中間本色 → 底部收暗」(例:藍 `#628CF2 → #3A5CD4 → #1E379E`;各色與灰階版見 defs),並套標題列陰影 `hdr`。
- 白色膠囊:白 → 專色極淺(例:紫 `#FFFFFF → #F1EAFD`)+ 輕投影 `row`。
- 徽章:球面 radialGradient(亮心左上 cx=0.35、cy=0.3)+ 投影 `obj`。

**立體層次(強制,四件套)**:
1. **雙層陰影**:主卡用 `shadow` = 遠景大柔影(dy=9、blur=12、14%)+ 近景實影(dy=2、blur=3、10%)。
2. **厚度邊**:每張主卡底部墊一層同形狀、下移 6px 的專色薄片(opacity 0.16),模擬卡片側面厚度。
3. **三段漸層**:深色列與膠囊一律採用(見上)。
4. **元件投影**:子卡 `card2`(dy=4、blur=5、13%)、項目列/技術膠囊 `row`(dy=2、blur=2、10%)、徽章與插圖 `obj`(dy=4、blur=4、28%)。

生動化僅限漸層與陰影,不加紋理、光斑、動態。全部濾鏡與漸層代碼見 assets/defs.svg。

## 3. 元件

- **群組帶/卡**:圓角 18、2px 主色邊框、淺漸層底、陰影 `shadow`。
- **標題列**:球面漸層徽章(左上白色高光橢圓,內置白色職能圖示或編號)+ 深色標題 800 + 灰色說明 15px,一律靠左。徽章半徑依元件層級:全寬層帶/大卡 24–28、堆疊層/側卡 20–22、KPI 組 18。
- **膠囊標籤**:深色漸層底、白字 700、全圓角,寬度貼合字數;放一項關鍵屬性(階段/入口/狀態),無則省略。
- **子卡**(帶內分欄):白底、淡邊框 1.5、圓角 12;頂部深色漸層標題列(白字 17/700、filter `hdr`)。
- **項目列**:白底、圓角 10、淡邊框、高 40、間距 10;左側 `chk`(主色、直徑 20)+ 文字 16/500。
- **預留/後續年度項目**:虛線框(dasharray 5 4)+ `clk` 灰時鐘 + 灰字,不打勾;整卡預留則外框改虛線(8 6)、膠囊改灰三段漸層 `gHdrGray`(不得單色平塗)。圖底附圖例:「實線=本案範圍」「虛線+時鐘=後續擴充」。
- **段落文字**(敘述型內容):16px/500、行距 26,左內距 24、右內距 14–18。
- **雙語排版**(原始資料為中英雙語時):中文為主行(標題 800 / 要點 15.5/500),英文為副行(11.5/400、灰 `#8A93A8`,置於中文正下方);標題、要點、連接線標籤一律成對呈現,不得只譯一半。
- **圖示補位原則**:卡片內容點少於 3 條時,以主題相關圖示或擬 3D 小插圖平衡版面密度(對話泡泡、文件、趨勢圖、成品示意等),**嚴禁為湊滿版面而自行增寫文字**;圖示只補氛圍、不載資訊。
- **連接徽章**:流程箭頭上有標籤時,以白底圓角小徽章(淡邊框 + `row` 投影)騎在箭頭/卡縫上呈現,內放「中文粗體 + 英文小字」,不用裸文字貼在縫隙。

### 3.1 間距與卡寬(留白控制,強制)

實務迭代歸納,違反即產生「留白過多」或「元件相黏」——交付前逐張量測驗證。

- **容器尺寸貼合內容(適用所有容器,不只卡)**:凡承載文字或圖示的容器——**卡、膠囊、深色磚、清單列、表格 cell、圓柱/環形/橫帶內的列**——尺寸一律 = 內容尺寸 + 內距(右內距 16–24px、且右內距 ≤ 左內距)。**嚴禁由外層容器反推內層尺寸**(例如「膠囊寬 = 圓柱半徑 × 1.66」「cell 寬 = 總寬 ÷ 欄數」「磚寬 = 區塊寬 ÷ 磚數」);外層只能決定**上限**(不得溢出),不得決定實際寬高。文字拆行變短後,容器要跟著縮。
  > **實例(踩過的坑)**:hub 內三條膠囊曾寫成「寬 = 圓柱半徑 × 1.66 = 219」,而最長標籤的內容只有 142 → 右側固定空 77px(佔 35%),短標籤更誇張。改為「內距 + 圖示徽 + 間距 + 最長標籤 + 內距」驅動後,填充率從 65% 升到 91%。
  > **例外只有三類**(其餘一律內容驅動):
  > ① **等寬欄**:同層級並排允許等寬,但欄寬須取到**該欄最寬卡所需的最小值**,不是把可用寬度等分(見下一條)。
  > ② **分佈帶**:用來群組 ≤5 個並列短項的全寬帶(如「共通能力」列)。**帶寬由版面決定,但帶內每一項仍須內容驅動並等距分佈**;整帶填充率門檻放寬為 55%。
  > ③ **頁面級帶**:標題帶、結論帶、註腳(§deck-anatomy L1/L5)。這類是版面結構元素、寬度由頁面決定,**不套填充率門檻**;其內容置中或靠左由版式決定。
- **等寬欄的欄寬取最小**:同層級須等寬,欄寬 = 該欄「最寬那張卡」所需寬度並**取到最小**。驗收點:**最寬(governing)卡的右內距落在 16–40px** 即欄寬正確。短卡因等寬而多出的內距屬必然、可接受;但若**單一張卡特別寬**(例如內含並排膠囊)把整欄撐大、害其他卡大片留白,應**優先縮短該卡元素**(如膠囊改短標籤)讓整欄收窄。
- **卡內子元件間距**:膠囊、徽章、內嵌標籤等子元件,彼此及與卡框**淨距 ≥ 12px**;多個膠囊/子元件並排時,彼此**淨距 ≥ 20px**,不得相黏。
  > **例外:貼標型元件**。刻意「貼」在另一元件上的標籤(如騎在圓柱頂緣的名稱膠囊、騎在流程箭頭上的連接徽章 §3),**與被貼物的重疊是設計語彙**,不適用 ≥12 淨距——強行分開反而讀成兩個不相干的東西。判準:貼標必須畫在被貼物**之後**(壓在上面)、且與被貼物**內部**的其他元件仍維持 ≥12。
- **標題與子元件垂直間距**:卡內標題與其下方膠囊列/子卡之間**淨距 ≥ 14px**,標題不得被子元件覆蓋(子元件不足以撐開時,加高卡片而非壓縮間距)。
- **留白判準(決策樹,統一水平/垂直/清單列;取代舊「清單列豁免/收緊/短卡55%/垂直留白」四條)**:每張卡依序判——
  ① **卡寬由內容決定**(非被標題或素材撐大)?→ **過**。此時清單列(全寬白橫條)列內文字靠左短屬**正常清單樣式、不算破綻**;卡寬由「最長列 / 最長標題 + 標題列右側元件」決定並取最小。
  ② 否 → **內容填充率 ≥ 75%**?(水平 = 文字/元件實佔寬 ÷ 卡寬;垂直 = 內文＋主圖佔高 ÷ 卡高,16:9/A4 等固定畫布尤重)→ **過**。
  > 門檻原為 55%,實測**過寬**——等於明文允許容器有 45% 是空的,成為「容器導向尺寸」的後門(填充率 67% 的鬆散卡片也能合格)。已提高到 75%,且本步是**補救後的驗收門檻**,不是繞過①的放行條件。
  ③ 否 → 判「留白過多」,擇一處置:(a)套 §14 圖文並置(素材左 35%＋清單右 65%);(b)主圖放大填滿「內文下緣→卡底」剩餘空間;(c)該欄放棄強制等寬、縮到內容寬(其餘卡仍各自貼合);(d)重新斷行。
  **清單列豁免**只在「至少一列夠長、卡寬由該長列決定」時成立;若**所有列都短(<50%)又被素材/標題撐大**,不適用豁免,回 ②。同一資料跨 1–3 級**維持等寬**以利對照。
- **量測自檢**:輸出後量每張卡「卡右緣 − 文字右緣」= 右內距;governing 卡落在 16–40px(或右側另有並排元件時,右內距被該元件佔用)、其餘卡無溢出;再依上方決策樹判填充率即通過。

## 4. 連接語彙

- **輻射連線**:點狀虛線 `#9AA7C8`、2px、dasharray「2 6」;群組端主色圓點(r=5.5–7)、核心端深色圓點;水平/垂直走線,落點在對方元素範圍內。
- **節點最小間距(流程/決策圖)**:相鄰節點(卡/菱形)之間**淨距 ≥ 40px**,確保連接箭頭清楚可辨、不相黏;卡寬**貼合內容**(見 §3.1);決策菱形與相鄰節點之間亦須留同等淨距。序列式排版時左右分支欄依內容自然延展並**垂直對齊**,避免一欄擠壓、另一欄大片留白。
- **迴圈/返回線**:回饋迴圈(如「不 OK → 重新確認」)一律走**節點之間的空檔**,轉折用直角;線與標籤與任何卡片**零重疊**,標籤放在空白處(勿壓在卡片或其他線上)。
- **流程軸線**:粗點虛線 5px、dasharray「0.1 13」、圓頭 + 強調藍 `#3E7BFA` 實心箭頭(**箭頭色規**:主軸箭頭=強調藍;支線/帶內/接入箭頭=來源或目標層專色);線下襯楔形 `gWedge`(z 序:楔形→線→卡片);每卡底邊短虛線垂降至軸線上的主色圓點(r=7、白邊 2、距卡底約 30px);箭頭與任何卡片 ≥ 6px 淨空。

## 5. 插圖(擬 3D)

> 插圖材質/立體的**唯一出處**。各級主圖豐富度見 §13、圖文並置的圖像尺度見 §14——那兩節只引用本節、不重述材質細節。

每卡一組「主物件+配件」,取材群組職能:申辦→螢幕/表單、數據→長條圖、審核→檢核板/放大鏡、通報→大聲公、管理→齒輪/人物、圖資→疊層、AI→晶片+星芒、基座→疊層方塊。插圖只做氛圍不載資訊;全圖複雜度一致、光源統一左上。**素材/插圖的色彩不受「全圖淺色」限制——可深色、飽和、發光以抓眼球(§2 表面分類);唯需全圖複雜度與色調協調,勿單卡突兀。**

立體感四件套:① 漸層上色(平面 linear、球體 radial)② 白色高光(圓形疊橢圓 opacity 0.25–0.55、平面疊斜切多邊形 0.10–0.22)③ 物件投影(filter `obj`)④ 地面扁橢圓陰影(色系深色、opacity 0.12–0.14)。

**外部素材庫(使用者自管,skill 不內含素材檔)**:去背 PNG 素材(命名 `P編號_英文名.png`)存放於使用者指定的素材目錄——Claude Code 以路徑指定(建議 `./geo-assets/`),Claude.ai 於對話中上傳所需素材。繪製第 3 級(§13)時**先向使用者確認素材來源**;有素材以 `<image>` 嵌入 SVG、依卡片比例縮放,**素材已自帶柔和光影,嵌入時不再疊 SVG 物件投影與地面橢圓**。

**缺件時的完整流程見 `references/asset-generation.md`(唯一出處)**:開「元素需求單」(項目 + 對應 prompt,參照 `scripts/asset_prompts.json`)→ 詢問是否用 AI 產圖 → 選供應商(**預設 Gemini,亦支援 OpenAI**)→ 確認環境(不 OK 先引導安裝)→ `scripts/gen_assets.js` 產圖 → 去背(Gemini 走 `scripts/chroma_key.js` 自動偵測底色;OpenAI `background=transparent` 直接透明;避免程式硬切照片)→ **留存素材與所用 prompt** → 驗收(邊緣無毛邊、無殘背、無文字)後嵌入。**API 金鑰一律從環境變數讀取,嚴禁寫進任何 skill 檔案。** 1–3 級或不產圖時依上方四件套現繪。

真 3D 元素一律外部生成;**整張圖永不交由影像生成模型重繪**;**承載資訊的文字(段落、數據、標籤、標題)一律由 SVG 負責**(生成圖中文字易錯)。**例外**:素材上**可保留簡短專案術語作為視覺標記**(如 `AI`、`KPI`、`GIS`、`API`、`SSO` 等已知短詞),條件為(a)僅限少數已知短詞、(b)**人工驗收拼字完全正確**(拼錯即重產或改由 SVG 疊字)、(c)不得用來承載真正的資訊內容。

## 6. 文字

字型:`Noto Sans TC, Noto Sans CJK TC, Microsoft JhengHei`(轉檔環境需 Noto CJK)。

### 6.1 字級依「頁面模式」分三組,不共用同一組 px

> **這是踩過坑改出來的,不要合併回單一表。** 三種頁面模式(§10)的**觀看距離完全不同**:自適應圖在螢幕 100% 檢視、16:9 投影在 3–10m 外看、A4 是紙本 40cm 閱讀。共用一組 px 再「微調主標」必然出錯——實測把自適應模式的 px 原封搬進 16:9 簡報頁,整組字級只有應有大小的 **67–83%**,主標最嚴重。

| 用途 | 自適應(px) | 16:9(佔畫布高 %) | A4(pt) |
|---|---|---|---|
| 全圖主標 | 40 / 900 | **5.2%** → 56 | **24pt** → 50 |
| 導言句 / 結論帶 | 26 / 800 | **3.0–3.5%** → 32–38 | **14pt** → 29 |
| 卡片 / 層標題 | 22 / 800 | **2.4%** → 26 | **13pt** → 27 |
| 全圖副標 | 17 / 400 | **1.9%** → 20 | **11pt** → 23 |
| 子卡標題列 | 17 / 700 | **2.0%** → 22 | **11pt** → 23 |
| 內文 / 項目 | 16 / 500 | **2.0%** → 22 | **10.5pt** → 22 |
| 說明文字 | 15 / 400 | **1.9%** → 20 | **10pt** → 21 |
| 膠囊標籤 | 14.5 / 700 | **1.9%** → 20 | **9.5pt** → 20 |
| 註腳 / 頁碼 | 13 / 400 | **1.4%** → 15 | **8pt** → 17 |

主標下加細藍底線 2.5px + 兩端小圓點(僅自適應與 16:9)。

- **16:9 錨定畫布高度百分比**:換到 1280×720 或 3840×2160 都用同一組 %,不要沿用 px。
- **A4 錨定實體 pt**:1240px 對應 210mm → `1mm ≈ 5.90px`、`1pt ≈ 2.08px`。**內文低於 10pt(≈21px)即不合格**;舊版「A4 主標降 34、其餘不變」的 16px 內文等於 **7.7pt**,遠低於印刷可讀下限——該寫法已作廢。
- 表中 px 僅為該模式**基準解析度**(自適應 1600–1720 寬 / 16:9 1920×1080 / A4 1240×1754)下的值。

### 6.2 下限不是目標

「內文 ≥ 16px」「全圖最小 14.5px」是**下限**,不是目標。以下限為目標會讓整組字級往下限塌陷(這是上述 67–83% 縮水的第二個成因)。順序必須是:**先依 6.1 定字級 → 再檢查有無觸及下限**,不可反過來。

### 6.3 斷行與塞不下的處理

斷行規則:全形 19–21 字/行、以填滿行寬為目標。塞不下時依序:**重新斷行 → 縮短文案(需回報使用者)→ 拆圖(§10)**。

**不得降字級。** 字級由頁面模式決定,為了塞下而降一級,整套字級系統就失效——舊版把「降一級字級」列為第二順位,已移除。

全形標點與「・」「|」直接使用。**英文/數字/代號詞(如 OIDC、SSO、API、RBAC、UPLOAD_*、PWA)視為不可分割單元,嚴禁跨行切斷**(自動斷行須以詞為界,勿在字元中間切;程式產圖時尤其注意)。

### 6.4 驗收方式

輸出 PNG 後量數處代表性文字的**字身高**(CJK 字身 ≈ 字級 × 0.88),依模式換算成 % 或 pt 與 6.1 比對。偏離 10% 以上代表**整組字級跑掉,不要只調那一行**。

## 7. 數據圖表語彙(統計/佔比/問卷資料)

共通規則:**多類別數據依配色順序輪用不同專色**——同一題的不同選項、不同列的人形圖、不同橫條、圓餅各扇區,各取一色,不得整組單色到底;僅單一指標(一條 bar、一個佔比)才用單色。KPI 列各組亦輪色。「未達成/其餘」一律中性灰 `#D9DDE3`(描邊 `#C6CCD6`);數值直標於元素旁(主色、700–900 字重),類別標籤 15–16px 灰 `#66708C`;不另設圖例(狀態圖例除外);數字必帶單位;關鍵數字放大至 24–32/900。

- **人形比例圖(pictogram)**:每列 10 個 `man` 人形(高 32、間距 8);達成=主色、部分達成=主色 opacity 0.55、未達=中性灰;列右側配百分比圓徽(主色圓 r=26 + 白字 18/900)與說明文字。
- **百分比橫條**:灰底軌道(高 30、全圓角、`#D9DDE3`)+ 主色三段漸層填充;數值標於條尾(主色 18/900)或條內白字;標籤在條右側。
- **單位方塊圖**:`unit` 圓角方塊(20×20、間距 6)橫列,達成主色/未達灰;適合「N 分之 M」「每 10 人有 M 人」。
- **圓餅/甜甜圈**:扇區 ≤ 6 片;最大扇區用主色,其餘同色相由深至淺;標籤以 1.5px 引線拉出,數值 20/900 主色 + 名稱 14 灰;甜甜圈中心放圖示或關鍵數字(28/900);圓餅整體套 `obj` 投影。
- **卡片迷你趨勢**:卡內折線/長條,主色 2.5px、不畫格線,只標首尾值。

## 8. KPI 大數字統計列

- 位置:全圖標題之下、主內容之上;3–5 組橫排等距。
- 每組結構:小圖示(主色線條圖示或球面徽章 r=18)+ 大數字(36–44/900 主色)+ 單位(18/700 同色、緊接數字)+ 標籤(15/400 灰,置於數字上方)。
- 組間以留白或 1px 淺灰豎線 `#E3E6EF` 分隔;可整列放於白卡(圓角 16 + `row` 投影)上,不用深色底。

## 9. 版型擴充細則

- **環形放射**:核心圓置中(白底 + 主題名 24/900 深藍 + `shadow`),外環以 3–8 段弧/扇承載類別(各取專色漸層);類別說明卡沿圓周外側放射排列,以短引線或弧段對應;含統計時 KPI 列置頂。
- **循環**:4–6 個節點(球面徽章 r=28 + 白卡標籤)沿圓周等分,節點間以主色 3px 弧線 + 實心箭頭順時針串接;中心放主題名或核心圖示。
- **階層—金字塔**:3–5 層梯形由上而下堆疊,依配色順序取色(頂層深、往下漸淺或逐色),層間留 4px 白縫,每層文字白字置中(不足時標籤外拉引線);整體套 `shadow`。
- **階層—樹狀**:頂節點用深色漸層標題列,子節點白卡(`card2` 投影),連線用直角線 `#9AA7C8` 2px;同層節點等寬等距。
- **標註型**:中央放情境示意區(擬 3D 插圖或示意底圖),四周說明卡(標準卡版式);每卡配編號圓徽(主色實心圓 r=14 + 白數字 15/700),以 1.5px 主色引線連至示意區對應位置,引線端點加 4px 圓點;編號自左上起順時針。
- **流程子樣式**:直線上升軸(預設)、山形折線(峰/谷交替放卡,折線段依序取專色)、箭頭鏈(chevron 箭頭一節一色、三段漸層,節下對應說明卡);皆遵守 §4 箭頭淨空與落點規則。
- **橫帶內小流程**:基礎層/支撐層橫帶內若含加工步驟(如「文件 → 向量化 → 知識庫」),以「圖示組 → 主色箭頭(附標籤)→ 圖示組 + 說明」的帶內敘事呈現,取代同款膠囊排排站;橫帶對主流程的支援關係以虛線箭頭連至對應階段卡並附標籤。
- **地理/地圖(geographic)**:以地圖輪廓(國/縣市/園區)為主結構元素,資料點以編號圓徽(§標註)或主色比例符號(圓面積/色階)直標於對應位置,引線拉出說明卡;色階圖須附刻度、比例符號須附大小圖例(此為 §11「直標」的例外允許)。地圖底圖走極淺灰輪廓、不搶前景資料;適合分布、據點、區域比較。
- **時間軸(timeline)**:純時序、無分支/回饋(有分支走「流程」、首尾相接走「循環」)。水平或垂直主軸(粗點虛線 + 端點箭頭),各時點以主色圓點錨在軸上、說明卡上下交錯(zig-zag)避免擁擠;每卡標日期/里程碑,依配色順序輪色;跨度過長就分段拆圖(§10)。
- **Venn/交集**:2–3 圓相交表達重疊關係;各圓專色半透明淺漸層(`mix-blend` 或降 opacity 讓交集自然疊色)、圓心放類別標題,交集區放共通項標籤;僅用於「關係/共通性」語意,勿用來表達流程或層級。

## 10. 頁面模式

| 模式 | 畫布 | 使用時機 |
|---|---|---|
| 自適應(預設) | 寬 1600–1720、高依內容 | 未指明用途的單獨繪圖 |
| 16:9 簡報頁 | 1920×1080 固定 | 指明放入簡報/proposal 單頁,或由 pptx 流程呼叫 |
| A4 直式報告 | 1240×1754 固定 | 指明放入報告/文件(docx/pdf) |

- 固定模式下:標題區高 ≤ 120(16:9)/≤ 140(A4);內容區置中排版;四周留白 16:9 ≥ 50、A4 ≥ 60。
- **內容超載一律拆成多張圖,禁止縮小字級或壓縮行距**;拆圖時每張仍須是完整可獨立閱讀的單圖單訊息。
- 上游流程(pptx/docx skill)呼叫時,依目標文件自動套用對應模式。

### 10.1 基準畫布與換模式的換算(所有絕對 px 的總則)

> 本規格其餘節次(§2 陰影、§3 圓角/內距/徽章半徑、§4 節點間距、§7 數據元件、§8 KPI、§9 版型、§12 裝飾)出現的絕對 px,**一律以「16:9 / 1920×1080」為基準畫布**。切換模式時依下表換算,不得原封沿用。

| 類別 | 換算方式 | 自適應 | 16:9 | A4 |
|---|---|---|---|---|
| **字級** | 依 §6.1 各模式**獨立錨定**(不是互相縮放) | 絕對 px | 佔畫布高 % | 實體 pt |
| **間距、內距、圓角、徽章半徑、圖示尺寸、節點淨距** | × 係數 **k = 該模式內文字級 ÷ 16:9 內文字級** | ×0.73 | ×1.00 | ×1.00 |
| **陰影 dy/blur、描邊寬、虛線 dasharray** | **不縮放**(視覺常數,縮放後反而失真) | ×1.00 | ×1.00 | ×1.00 |
| **opacity、漸層停點、比例式版型(§14 的 35:65)** | 本來就是比例,不動 | — | — | — |

> **k 為什麼用「內文字級比」而不是「畫布尺寸比」**:留白的正確參照是文字大小,不是紙張大小。若改用畫布高度比,A4(高 1754)會得到 ×1.62,但 A4 寬僅 1240(比 1920 窄),間距放大 1.62 倍必然橫向溢出。以內文字級為錨可同時滿足兩個方向。

換算後一律取整;係數僅適用於**同一視覺語言在不同畫布上的複製**,若該模式另有專屬版式(如 A4 單欄),以該版式的內容驅動尺寸為準(§3.1)。程式實作的唯一出處為 `scripts/page_modes.js`——**生成器一律從該檔取字級與 k,不得自行寫死**。

## 11. 易讀三原則(貫穿所有版型)

1. **單圖單訊息**:一張圖只回答一個問題;資料含多個主題時拆成系列圖。
2. **直標於圖上**:數值、類別直接標在元素旁,不依賴另設圖例(既有/預留狀態圖例除外)。
3. **數字說人話**:必帶單位、關鍵數字放大加粗;比較性數據排序後再呈現(大→小或時序)。
4. **不只靠顏色(無障礙)**:顏色是身分輔助、不是唯一線索——八色輪用時紅(`#C62839`)與綠(`#1F9254`)相鄰對紅綠色盲難分,故群組/類別一律另配**徽章圖示或文字標籤**,狀態(達成/未達/預留)另以形狀區分(勾/時鐘/虛線),使去色後仍可辨識。相鄰資料序列盡量避免紅接綠,可改插入橘或藍灰間隔。
5. **三段敘事骨架**:整張圖依「引子(標題/主訊息)→ 核心(主內容/數據)→ 結論(重點卡/KPI/收束)」安排閱讀順序,讓讀者一眼知道從哪看到哪;單訊息圖也應有明確視覺起點與落點。
6. **F/Z 視線動線**:重要元素順著自然掃視路徑放——密集資訊走 F 型(左上起、由上而下掃),簡潔展示走 Z 型(左上→右上→左下→右下);標題、關鍵數字、CTA/結論落在動線轉折點,連接線走向盡量順動線不逆行。

## 12. 裝飾層(填補留白,選用)

> 裝飾與場景的**唯一出處**。各級裝飾/場景開關見 §13、場景素材落地規則見 §14——那兩節只引用本節。

版面出現大面積留白(側掛式版型的 L 型角落、環形版型的四隅等)時,依本節填補。**裝飾一律不載資訊、不與內容元素重疊**,內容忠實原則不受影響。

- **背景**:純白可改為極淺縱向漸層(白 → `#EAF1FA` 一帶),僅限海報式/場景式圖表;簡報內容頁仍以純白為預設。
- **基礎裝飾**:柔光圓(四色淺底、opacity 0.4–0.55、r 55–110)、點陣(5×3、r 2.4、`#9DB4DC`)、十字星與四角星芒,散布於留白角落。
- **主題圖示徽底**:柔光圓上疊一個與主題相關的線條圖示(文件、節點網、放大鏡、晶片、齒輪、對話泡泡⋯依題材選),描邊取圓底同色系加深一階、stroke 2.5–4、fill none、opacity 0.6–0.85;零星小留白配獨立小型線條圖示(代碼括號、星芒等)。
- **主題呼應元素**:依題材加入場景意象——底座平台(同心橢圓 + 地面放射線)、城市天際線剪影(含白色窗格)、KPI 擬 3D 小圖示(金幣疊、人群、新芽、地球)等;色彩一律取淺色系。
- 用量節制:裝飾總面積不搶過內容;所有裝飾置於內容圖層之下。

## 13. 豐富度等級(3 級)

產圖前必須確認等級:使用者已指定則採用;未指定時先詢問並附情境建議——草稿/討論=1、簡報內容頁=2、封面/海報/重點頁=3。三級對應三種真實用途(草稿、內文、主視覺);「裝飾」與「場景」為級內開關,不再各佔一個等級。

> **適用範圍**:3 級主要規範**卡片/角色類**版型(中心輻射、分組並列、階層、流程卡…)。**純數據圖**(§7)與**純流程/連接圖**的豐富度主要由 §7/§9 決定,級別只影響裝飾與背景層,不套「嵌素材場景」。

- **第 1 級|極簡線框**:單色細線(`#A7B0BF`)、無填色;§2 立體與 §12 裝飾全部關閉。用於構圖審查、黑白列印、高密度草稿。
- **第 2 級|立體(預設基準)**:立體四件套(§2)全套 + 裝飾層(§12);主圖區一律達 **「第 4 階擬真」**——即精緻向量 3D(多層漸層+環境遮蔽+鏡面高光+倒影+左上光源),**不用扁平線圖示**。材質/立體細節見 §5,參考實作見 `scripts/gen_role.js` 的 `richIllo()`。**裝飾層可關**(需要極簡時)。
- **第 3 級|素材場景**:第 2 級 + 主圖區嵌入外部生成擬真素材(每卡至多 1 件,§5)+ 全景場景元素(天際線剪影等,§12);素材與場景成為版面要角但數量節制。**場景可關**(只要素材、不要場景時)。

通則:第 3 級素材一律取自外部素材庫(§5),整張圖由 SVG 組裝、文字與版面 100% 可控;**嚴禁將整張圖交由影像生成模型重繪**(必產生文字錯誤與重複標籤)。

**三級同構原則(強制)**:同一份資料的 1–3 級,**版面骨架完全相同**(卡尺寸、位置、連線等骨架元素一致,以利等寬對照;骨架元素依版型而定——角色/中心輻射含 hub、流程含軸線+基礎帶、環形含核心圓);級與級的差別**只在主圖區與裝飾/場景豐富度遞增**——L1 線圖示 → L2 擬 3D SVG 插圖+裝飾 → L3 嵌入真素材+場景。切換等級不得改動結構。

## 14. 圖文並置卡與 hub-spoke 版式(帶素材的卡/中心輻射圖主推)

當卡片要放主題素材(第 3 級,或任何等級的重點卡),**不得把素材塞在標題右上角、讓清單列撐滿全卡(會造成每列右半大片留白)**。改用本節版式:

- **卡內圖文並置(比例 35:65)**:卡身分「**主圖區 + 文字區**」兩欄。主圖區佔卡內寬約 **35%**(放一整塊領域主圖/擬 3D 插圖/真素材),文字清單縮到右側 **65%** 窄欄並填滿。列寬由此變窄、右半不再空。
- **左右鏡像**:側掛式版型(中心輻射)中,**左欄卡主圖在外側、文字朝內(向核心);右欄相反**。文字靠中央 → 連線最短、版面對稱。
- **三級圖像尺度**:核心徽章(主題錨)＞ 卡主圖(角色/群組領域)＞ 列首圖示(該列功能),三者同一套視覺語言,不混用(勿等角立體件與扁平剪影並存)。
- **hub-spoke 連線佔中央帶**:中心輻射版型的核心與側欄之間的中央縱帶,**必須由連線(§4)、KPI 列或核心卡本身佔用**,不得僅以裝飾/場景素材填空;側欄卡內側邊 → 核心卡邊緣節點,依 §4 連接語彙(≥6px 淨空、走空檔、落點在對方範圍內)。
- **核心/hub 卡維持淺色**:核心卡沿用其專色淺漸層底(如青綠 `gCore`)+ 深色列(`gCoreBar`),與周圍卡同屬淺色系、遵守 §2「禁止深色大面積」;hub 地位改由「置中節點徽章 + 較大標題 + 邊緣連接節點」凸顯,**不靠深色大底**。(此為明確結論:核心卡不改為深色。)
- **場景素材必須落地**:§12 的場景意象(天際線、地形)須與其他場景元素**共用同一地平線、同一視覺語言**,退居內容圖層之下;**不得以孤立浮空的立體件塞入留白**(否則讀作「為放而放」)。
