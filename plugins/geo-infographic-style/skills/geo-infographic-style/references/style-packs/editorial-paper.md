# Editorial Paper(美編級編輯風)style pack

使用者指定「美編風／雜誌風／編輯風／設計感」時套用本 pack(`--palette=editorial-paper`)。與預設八色風**並存不混用**;同一份簡報選定一套風格後全程一致。

## 設計哲學:減法

工程師圖與美編圖的差距不在效果多寡,在**減法**。本 pack 的一切規則都從三個「去」推導:

| 去什麼 | 換成什麼 |
|---|---|
| **去框**:嚴禁描邊盒子(圓角矩形+彩邊) | 髮線(1px `ink.line`)、留白、柔和橢圓陰影分層 |
| **去色**:嚴禁類別色大面積出現 | 一頁一主色(accent)+ 紙感中性底;類別色僅佔 **~5% 面積**——色點、眉標文字、金額短線、tick 細節 |
| **去置中**:嚴禁全頁置中對稱 | 左對齊為預設;**不對稱構圖**(1/3 敘事欄 + 2/3 內容區為基本型) |

省下來的視覺預算**全部花在字體排印與留白**。

## 色彩

- 中性色(`tokens.json` palettes.editorial-paper.ink 唯一出處):紙感底 `pageBg #F8F6F1`、墨色 `title #1D2433`、內文 `body #3A4256`、次要 `muted #8A8577`、髮線 `line #E3DFD6`。
- accent 主色:每頁**選一色**(預設 blue),用於標題色線、引言塊左線。
- 類別色(八色 hues 沿用預設風色值):只出現在眉標文字、單位色點、金額上方短線(34×4)、匯流 tick+圓點。**任何超過小標籤尺度的類別色面積都是違規**。
- 禁止:漸層底、深色標題列、球面徽章、發光效果。

## 字體排印(本 pack 的主角)

| 元素 | 規格 |
|---|---|
| 頁面大標 | 52/900 墨色,**可拆多行**,上方 56×5 accent 色線,左對齊 |
| 導言/內文 | 20–22/500 `body` 色,行距 33–37,左對齊 |
| **眉標(eyebrow)** | 15/700–800 + **letter-spacing 2–4px**;類別眉標用類別色,功能眉標(如「工作內容」)用 muted。微字語感靠**字距**,不靠縮字級(§6.2 下限 14.5 仍適用——validator 實測擋過 12–14px) |
| 單位/區塊名 | 28–30/900 墨色 |
| **裸數字** | fitDisplay 上限 ~84/900 墨色、letter-spacing -1;單位以 20/700 muted 小字緊隨。**數字用墨色不用類別色**(數字是主角,類別色只做數字上方短線) |
| 引言塊 | 23/600 `body`,行距 40,左側 3.5px accent 縱線,hi 關鍵詞 900 墨色 |
| 微標(如 MOU) | 15/600 muted + ls 1.5,靠右;不做膠囊 |
| 註腳 | 15/400 muted |

## 版式

- **基本型 1/3–2/3**(`templates/editorial-split.js`):左欄=色線+大標+導言+引言塊(結論句移入左欄,製造不對稱敘事)+小註;右區=N 欄無框內容,垂直髮線分欄,欄內「素材→眉標+微標→名稱→內文→裸數字(底對齊)」。
- **匯流/模組列**:底部 1px 髮線 + 各欄專色 2px tick+3.5px 圓點,收進一行 interpunct(・)分隔的文字列——不做加框橫帶。
- 金額/數字**底部對齊**跨欄同基線;內文長短差留白自然呈現,不硬撐。
- 留白是元素:左欄下方大片留白屬刻意呼吸,不觸發補位。

## 素材

- 一律**場景式**(`gen_scene.js` + Nano Banana Pro + 風格參考圖 + `IMG_AR=3:2`),多元件微場景呼應該欄文字重點。
- 落在**柔和橢圓陰影**(墨色 opacity 0.08)上,**不裝圓圈框、不裝任何框**。
- prompt 色系呼應該欄類別色,矮彩度可(素材是唯一允許較大類別色面積的元素)。

## 豐富層(畫面密度的編輯手法——加氛圍與細節,不回頭加盒子)

使用者要「更豐富」時,依序考慮以下手法,全部維持減法語言:

- **柔和色暈**:accent 色 radial 漸層(7% → 0)大橢圓 1–2 枚,對角配置(右上/左下),置於內容之下。
- **ghost 序號**:各欄大型編號(01/02/03,92/900,墨色 fill-opacity 0.07,ls -2),素材壓其上製造層次。
- **大型裝飾引號**:引言塊左上,serif「“」76/900、accent 色 18%。
- **比例髮線**(優先——有資訊含量的豐富):數字下方 3px 全寬髮線軌 + 類別色比例填充(值÷最大值);數值已直標,線僅視覺比例。
- **第二視覺焦點**:左欄底部合計/總量大數字錨點(眉標+accent 短線+76/900 裸數字),填補留白並形成對角動線。
- **印刷 meta**:四角 L 形角線(1.5px 髮線色)+ 右下頁碼(15/700 ls2 muted)。
- **每格配圖**(圖文並置):數據格右側放該格的訊息式素材(垂直置中+柔影,~140 尺寸);說明列排在素材帶下緣以下用近全寬,避免窄欄孤字斷行。
- **棋盤式淡色色塊**:(row+col) 偶數格以該格專色 light 滿格出血上色(無框、直角)——雜誌分區手法,增加色彩密度而不回到卡片。
- **主視覺敘事化**:hero 場景應**講頁面的核心訊息**(如「資料斷點」= 輸送帶斷裂+資料方塊掉落),不只放類別物件;用 gen_scene + 風格參考圖產製。
- 用量原則:氛圍類(色暈/ghost/引號/色塊)不載資訊、不與內容重疊;資訊類(比例線/合計/配圖)須逐字或同簡報既定事實。

## 與引擎的關係

版面仍由引擎與 validator 管(inside/noOverlap/字級下限/標點);本 pack 只改視覺語言,不豁免任何內容忠實與驗收規則。獨立評審(qa-review)照走。

## 待擴充

- 其他版型的 editorial 變體(KPI 數據列、權重分流、方案卡)——以本檔規範為準逐一改寫,而非在舊模板上加開關。
- 中性色深色版(editorial-dark)、A4 直式編輯版式。
