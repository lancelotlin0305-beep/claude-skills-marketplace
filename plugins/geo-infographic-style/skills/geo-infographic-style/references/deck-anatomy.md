# 簡報頁解剖(page chrome)——五層結構模型

> 適用於「整份簡報／proposal 的內頁」而非單張獨立圖表。單張獨立圖表走 style-spec §10「自適應」即可,本文件規範的是**16:9 內頁的固定框架**。
> 本文件只規範**框架與層次**;色票、字級、素材風格由 style pack 決定(見 `style-packs/`)。

## 1. 五層模型

任何一頁都可拆成五層,由下而上疊:

| 層 | 名稱 | 內容 | 產製方式 |
|---|---|---|---|
| **L0** | **底圖 plate** | 頁底極淺漸層 + 低透明度情境影像(廠房/天際線/地圖輪廓/電路走線)+ 可選外框線 | 每份簡報 1–3 張通用底板,**全份重複使用**;可 AI 產或 SVG 現繪 |
| **L1** | **標題帶** | 主標 + 副標(+ 左側色條或底線)+ 右上 logo 帶 | SVG |
| **L2** | **圖框層** | 卡、橫帶、表格、膠囊、深色標題列 | SVG |
| **L3** | **素材層** | 擬真 3D 去背件 / 徽底線圖示 / 情境照片 | 3D 件走 AI 產圖;線圖示 SVG |
| **L4** | **連接層** | chevron 箭頭、發光曲線、點狀虛線、直角樹狀線 | SVG(輝光用 filter) |
| **L5** | **結論帶 + 註腳** | 全寬深色圓角帶(白字結論)、著作權註腳、頁碼 | SVG |

**分層鐵則**:L0 與 L4 的裝飾**永不承載資訊**;L3 素材**永不承載文字**(短代號例外見 style-spec §5);所有資訊文字一律在 L1/L2/L5。

## 2. 16:9 內頁座標規範(1920 × 1080)

```
┌────────────────────────────────────────────────────┐ 0
│  L1  主標 baseline y=80          [logo 帶 右上]     │
│      副標 baseline y=116                            │
├────────────────────────────────────────────────────┤ 150
│                                                    │
│  L2 / L3 / L4  內容區  y 150 – 880                  │
│                                                    │
├────────────────────────────────────────────────────┤ 880
│  L5  結論帶  y 898 – 984  (全寬 x 60 – 1860, r=14)   │
├────────────────────────────────────────────────────┤ 1000
│  註腳 y=1032 (左)                        頁碼 (右)   │
└────────────────────────────────────────────────────┘ 1080
```

- **左右安全邊距 60px**,所有內容不得越界。
- **字級一律以「佔畫布高度的百分比」定義,不用絕對 px**。簡報頁會被整頁縮放到螢幕或投影,px 沒有意義;沿用單張圖表模式的 px 會讓整組字級縮水 20–30%。比例表見所用 style pack。
- **內容區高度 730px** 是硬上限;塞不下一律拆頁,**禁止縮字**(承 style-spec §10)。
- **結論帶為選用但強烈建議**:有「本頁要讀者記住的一句話」時就放,能讓整份簡報節奏一致。沒有結論句時整區留白,不要用裝飾填。
- **導言句**(結論帶的反向:放在內容區最上緣的一行 26/800 深色句)用於「先講結果再展開」的頁,佔 y 150–195,內容區順延到 210。

## 3. 各層細則

### L0 底圖 plate
- 底色:白 → 極淺藍灰縱向漸層(頂 `#FFFFFF`、底 `#EDF3FB` 一帶)。
- 情境影像:置於**右下或整條底緣**,`opacity 0.08–0.15`,不得延伸到內容區文字下方造成干擾。
- 通用底板數量控制在 1–3 張並在全份重複;每頁換一張會讓簡報看起來散。
- 可選 1px 外框(`#D8E2F0`)或四角虛線框,整份要嘛都有要嘛都沒有。

### L1 標題帶
- 主標 40/900,深色主題色;副標 18/500,主標下 36px。
- **左側色條**(寬 8、高 = 主標高、r=4)與**底線**(寬 = 主標寬、高 2.5)兩種變體,**一份簡報只能選一種**。
- logo 帶靠右上,高度 ≤ 44,與主標基線對齊區間內。

### L2 圖框層
- 卡圓角 14–18、1.5–2px 專色邊、淺色底(承 style-spec §2 表面分類)。
- **深色重點卡**每頁至多 1–2 張(結論帶不計),白字對比 ≥ 4.5:1。
- 表格式版型:表頭列深色漸層白字,資料列白底 + `#EDF1F8` 斑馬紋,首欄配專色圖示徽章。

### L3 素材層
- 每頁擬真 3D 件 **≤ 8 件**;超過會讓頁面失焦。
- 同頁所有 3D 件必須**同一光源、同一輝光強度、同一材質語言**(見 style pack 的素材風格鎖)。
- 小圖示(徽底內)一律 SVG 線圖示,**不要混用小尺寸 3D 件**——縮到 40px 以下的 3D 件只會變成一團色塊。

### L4 連接層
- **chevron 箭頭**:主流程用,長 48–64,專色三段漸層,與兩端元素淨距 ≥ 12。
- **發光曲線**:表達「資料匯流」時用,貝茲曲線 + 輝光 filter,起訖點吸附在元素邊緣節點(小圓點 r=4)。
- **直角樹狀線**:WBS/階層用,2px,轉角不倒圓。
- 所有連線與卡片**零重疊**(承 style-spec §4)。

### L5 結論帶
- 全寬 x 60–1860,高 76–90,r=14,深色三段漸層 + `shadow`。
- 左側置一個 r=22 球面徽章(圖示白色),文字 24–26/800 白字,**關鍵詞轉高亮色**(青或黃)。
- 註腳 13/400 `#8A93A8`,頁碼同級靠右。

## 4. 跨頁一致性(整份簡報的硬規則)

1. **概念—顏色綁定**:同一個概念(模組、部門、階段)在**整份簡報中永遠同一顏色**。這是最容易破功、也最傷專業感的一條——交付前務必跨頁掃一次。
2. **同義版型同一佈局**:同樣是「五個模組並列」,不同頁不得一頁用橫帶、一頁用卡片網格。
3. **底板輪替固定**:L0 用哪張、哪幾頁用,開場就定好。
4. **結論帶語氣一致**:都用斷言句或都用描述句,不混。
5. **註腳與頁碼位置逐頁不變**。
