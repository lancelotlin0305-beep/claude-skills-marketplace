# 知識萃取檔 HTML / SVG 產製規範

輸出單一 HTML 檔,**不依賴任何外部資源**(無 CDN、無外部字型、無網路請求)。
會議知識檔常在無網路的內部環境或離線筆電上開啟,拉不到資源就整份毀掉。

模板:`assets/knowledge-extraction-template.html`。

## 1. 設計定位

這是**檔案卡櫃**,不是簡報。讀者是半年後接手的人,他要能快速找到需要的那張卡。
所以:資訊密度高、分類清楚、可篩選、可列印。**不要做成行銷頁**。

克制原則:唯一允許張揚的是知識分布時間軸(見 §4),其餘一律安靜。

## 2. 設計 token(照用,不要自行更換配色)

```css
--paper:      #F1F3F6;   /* 底,冷調近白,刻意避開米黃 */
--card:       #FFFFFF;
--ink:        #1B2430;   /* 主文 */
--ink-soft:   #5A6675;   /* 次要文字、標籤 */
--rule:       #D5DAE1;   /* 分隔線 */

--dom:        #2F5FA8;   /* 領域知識 靛 */
--tec:        #0E7C6B;   /* 技術知識 青綠 */
--pro:        #B26A00;   /* 流程知識 琥珀 */
--acc:        #9B2C3B;   /* 對象脈絡 暗紅(限閱)*/
--pra:        #6B4E9B;   /* 應對經驗 紫 */
--warn:       #B26A00;   /* ⚠️ 缺漏標記 */
```

字型全部用系統堆疊,不引外部字型:

```css
--serif: "Noto Serif TC","Songti TC","Source Han Serif TC",Georgia,serif;
--sans:  "Noto Sans TC","PingFang TC","Microsoft JhengHei",system-ui,sans-serif;
--mono:  ui-monospace,"SFMono-Regular",Menlo,Consolas,monospace;
```

- 卡片標題、章節標題用 `--serif`(檔案感)
- 內文、標籤用 `--sans`
- **ID、時間戳、參數、指令一律 `--mono`** —— 這些是要被精確複製的東西,等寬字讓人一眼認出


## 4. SVG:知識分布時間軸(簽名元素)

**這張圖回答一個真問題:這場會議的知識集中在哪一段?**
常見結論是「精華全在最後 20 分鐘」或「開場 10 分鐘後就沒有新東西了」——
這對安排下次會議的節奏有實際幫助,不是裝飾。

規格:

- `viewBox="0 0 900 130"`,`width="100%"`,`preserveAspectRatio="xMidYMid meet"`
- 基準軸:y=90,自 x=40 至 x=860,`stroke: var(--rule)`,`stroke-width: 1`
- 刻度:每 15 分鐘一格,下方標 `--mono` 小字時間
- 每張卡片一個標記:
  - x = `40 + (卡片秒數 / 會議總秒數) × 820`
  - y = 90 減去該時間點附近的堆疊高度(同時間多張卡往上疊,每張 14px)
  - 形狀:`<circle r="5">`,填分類色
  - `ACC` 卡外加 `stroke: var(--ink)` 虛線圈,視覺上就看得出限閱
- 每個標記加 `<title>` 顯示卡片 ID 與標題(原生 tooltip,不需 JS)
- 標記帶 `data-cat` 屬性,供篩選時降低不透明度至 0.15

**模式 B(無時間戳)整塊省略**,改在該位置放一行說明:
「本場無逐字稿時間戳,無法產生知識分布時間軸。」
**不要用假座標硬畫** —— 一張位置是編的圖,比沒有圖更糟。

## 5. SVG:分類分布堆疊條

- `viewBox="0 0 900 64"`
- 單一水平堆疊條,x=40 至 x=860,高 28,y=8
- 各段寬度依該分類卡片數佔比;段內若寬度 > 46 則置中標數字(白字 `--mono`)
- 條下方為圖例:色塊 + 分類名 + 數量
- 某分類為 0 時**不畫該段、圖例也不列** —— 不要留空槽

## 6. 互動(原生 JS,約 40 行,無框架)

**分類篩選** —— 點擊 chip 切換該分類顯示;多選;全不選時顯示全部。
同步調整時間軸標記的不透明度。

**🔒 隱藏切換** —— 一鍵隱藏所有 `ACC` 卡片與其時間軸標記。
按鈕文字明確:`隱藏限閱內容` / `顯示限閱內容`,不要用圖示代替文字。
**預設為顯示**,但按鈕要明顯 —— 這是給簡報 / 螢幕分享時臨時用的。

無障礙底線:`:focus-visible` 有可見外框、chip 用 `<button>` 並帶 `aria-pressed`、
`prefers-reduced-motion` 時停用過場。

## 7. 列印樣式

`@media print`:白底、篩選列與切換鈕隱藏、卡片 `break-inside: avoid`、
展開所有被篩掉的卡片(列印應該是完整的)、`ACC` 卡保留但頁首加註「本頁含限閱內容」。

## 8. 卡片標記

- 左側 4px 分類色直條;分類 chip 用該色 12% 透明底 + 該色文字
- `ACC` 卡:標題前加 🔒,卡片外框改該色 1px 實線
- 信心「低」的卡片,信心欄位標 `⚠️` 並用 `--warn`
- **「踩過的坑」欄位加淡色底突顯** —— 這是全檔最有價值的一欄,不要讓它跟其他欄位長得一樣
- 空欄位**整欄不顯示**,不要印出「無」或留白標籤

## 9. 檔名

```
YYYYMMDD_<會議名>_知識萃取_v<n>.html
```

模式 C 跨會議時,檔名用**本次會議日期**,但內容含前次卡片的延續狀態(見 `cross-meeting.md`)。
